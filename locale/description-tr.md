# Map PNG

Harita düzenleyicideki Harita Özellikleri bölümünde mini haritanın altındaki düğmelerle arazi ve yükseklik haritalarını PNG olarak içe veya dışa aktarın. Bağlı PNG’leri yeniden yüklemek için Yenile’yi kullanın. İçe aktarma, yeni araziyle çakışan nesneleri kaldırabilir.
