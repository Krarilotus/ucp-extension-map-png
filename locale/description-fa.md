# Map PNG

نقشه‌های عوارض زمین و ارتفاع را به‌صورت PNG با دکمه‌های زیر نقشهٔ کوچک در «ویژگی‌های نقشه» ویرایشگر نقشه وارد یا صادر کنید. برای بارگذاری دوبارهٔ فایل‌های PNG پیوندداده‌شده از «بازآوری» استفاده کنید. وارد کردن می‌تواند اشیای ناسازگار با زمین جدید را حذف کند.
