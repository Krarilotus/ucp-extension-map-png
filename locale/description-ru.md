# Map PNG

Импортируйте или экспортируйте карты рельефа и высот в формате PNG с помощью кнопок под мини-картой в «Свойствах карты» редактора. Кнопка «Обновить» перезагружает связанные PNG. При импорте объекты, несовместимые с новым рельефом, могут быть удалены.
