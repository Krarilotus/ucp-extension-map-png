# Map PNG

Importez ou exportez le terrain et les hauteurs en PNG grâce aux boutons situés sous la minicarte dans les Propriétés de la carte de l’éditeur. Utilisez Actualiser pour recharger les PNG liés. L’importation peut supprimer les objets incompatibles avec le nouveau terrain.
